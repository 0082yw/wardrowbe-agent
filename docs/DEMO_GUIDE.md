# Wardrowbe 项目演示指南

演示时长 3–5 分钟。默认展示已有成功结果和脱敏验收记录。现场发起模型请求须事先确认环境、预算与授权。

| 时间 | 操作 | 讲解 |
|---|---|---|
| 0:00–0:45 | 打开现有账号的衣橱页 | 介绍用户隔离、关键词和条件筛选。 |
| 0:45–1:30 | 展示单品详情、标签入口与归档筛选 | 展示名称、分类、颜色及图片。正式数据只展示，不现场编辑或删除。 |
| 1:30–2:45 | 打开已有 Agent 成功预览或使用脱敏记录 | 展示衬衫与牛仔裤组合、两张签名图片和三项文案。指出穿搭来自真实候选，预览不保存。 |
| 2:45–3:45 | 用架构图追踪一条请求 | 从 FastAPI、身份绑定、ToolNode 和 ToolMessage 讲到 Qwen3 文案及 Schema 校验。 |
| 3:45–5:00 | 对照真实验收记录和边界 | 展示历史 GPU 1 证明与最新请求的 `unknown`。说明旋转 Worker 的验收和当前状态。 |

最新成功请求 3.51 秒，模型调用一次，两个图片请求均 HTTP 200，三项文案均未回退。这是一次实测。历史证明只说明原请求的实际设备。禁止在演示中展示 Token、签名 URL、真实连接凭据或私有账号信息。

现场演示遇到资源保护、SSH 断开或缺失证据时，切换到 [验收记录](FINAL_PROJECT_REPORT.md) 讲解已有结果。架构图和排障说明见 [系统架构](ARCHITECTURE.md) 与 [部署手册](DEPLOYMENT.md)。
