本文件记录受控部署环境已经完成的技术验证。发布副本的服务器、路径和 GPU UUID 使用示例值，部署时需要准备自己的可信配置。

## 性能观测

一次真实穿搭请求耗时 3.5065 秒，其中模型 HTTP 调用一次、耗时 3.0592 秒，输入 282 tokens、输出 32 tokens，正常结束。工具执行一次，展示两件真实衣物，三项文案未触发回退。两张签名图片均返回 HTTP 200。该请求没有同窗口设备证明，因此 GPU 状态为 unknown。

另一条历史请求获得完整 GPU 证明，包含指定设备、模型进程、37/37 层和显存采样。历史证据仅属于原请求。以上均为单次观测，不构成吞吐、并发或 SLA 承诺。
